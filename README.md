## 💼 Experience

### ☀️ Solarmonitoring — ML & Software Developer

**2025 – Present**

I develop machine learning and software solutions for photovoltaic power forecasting.

One of my main achievements was improving a PV forecasting model from **6.51% to 4.56% nMAE**, corresponding to approximately a **30% reduction in prediction error** for periods with `P > 0`.

My work includes:

* Developing and deploying ML models for PV power forecasting
* Processing and integrating meteorological data
* Designing REST APIs for prediction and weather data
* Building database backends and data pipelines
* Containerizing and deploying applications with Docker

**Main technologies:** Python · PyTorch · Vertex AI · Docker · MySQL · REST APIs

### 🚗 Digiteq Automotive — Junior QA & Test Developer

**2022 – 2025**

Worked on Hardware-in-the-Loop (HIL) testing for automotive systems.

* Developed a Python framework for automated infotainment UI recognition

* Prepared QA documentation and onboarding materials

**Main technologies:** Python · Git · CANoe · VeriStand · LabVIEW · MATLAB · JIRA · Confluence
